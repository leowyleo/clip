# Clip v0.1.0

Clip is a local, clipboard-first screenshot utility for macOS 13 and newer.

## What is included

- Free rectangular capture directly to the clipboard.
- App-agnostic scrolling capture controlled by the user.
- Minimal and Advanced capture experiences.
- Local annotation tools and Vision OCR in Advanced mode.
- English interface by default, with Simplified Chinese available in Settings.
- Universal support for Apple Silicon and Intel Macs.

## Install

1. Download `Clip-v0.1.0-macOS-universal.zip` from this release.
2. Unzip it and move `Clip.app` to Applications.
3. Open Clip. If macOS blocks the first launch, open **System Settings → Privacy & Security**, scroll to Security, and click **Open Anyway** for Clip. Confirm **Open** when asked.
4. Start a capture and allow Clip under **Screen & System Audio Recording** when macOS asks.

## Important security note

This community preview is locally code-signed but is **not signed with an Apple Developer ID and has not been notarized by Apple**. macOS therefore requires the explicit first-launch approval above. Download Clip only from this repository's official release page. Do not disable Gatekeeper globally.

Clip processes captures locally. It does not upload screenshots, record video, or require an account.
