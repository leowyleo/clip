Report a problem

For reproducible bugs, please open an issue on GitHub Issues and include your macOS version, Mac architecture, capture mode, and a short description. Do not attach private screenshots unless you are comfortable sharing them publicly.

You can also contact leowy.lwy@gmail.com.

Before contacting us

  • Confirm Clip is allowed under System Settings → Privacy & Security → Screen & System Audio Recording.
  • Try the capture again with a smaller, stable region.
  • For scrolling capture, scroll the underlying app normally and use Finish when the intended content is complete.
