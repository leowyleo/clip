Clip · macOS

Frame it, paste it.

A local-first screenshot utility that takes the shortest path from something you see to something you can paste.

PrivacySupport简体中文

Press a shortcut, select any rectangle, and release. Clip copies the image to the system clipboard immediately.

For scrollable content, select a viewport and scroll normally. Clip keeps in-memory ScreenCaptureKit frames, verifies their continuity, and copies the stitched image when you finish.

Designed to stay out of the way

Clip has no account, cloud sync, analytics, or app-specific adapters. Captures and optional OCR run locally. If a scrolling result cannot be verified, Clip reports a failure instead of returning a plausible but incorrect image.
