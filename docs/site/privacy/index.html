Privacy

Clip is designed to process screenshots on your Mac.

ClipSupport中文

Last updated: September 11, 2026

What Clip processes

When you start a capture, Clip reads only the screen pixels in the area you select. Scrolling capture keeps screen frames in memory while you scroll and uses them to verify and compose the result. Advanced OCR uses Apple’s on-device Vision framework.

What Clip stores or sends

  • Clip does not require an account and does not send screenshots, OCR text, or usage data to a server.
  • Clip has no analytics, advertising, tracking, or cloud sync.
  • The normal result is written to the macOS system clipboard. Clip does not create an image file unless you explicitly choose Download.
  • When you choose Download, Clip writes a PNG to your Downloads folder. Capture mode and shortcut preferences are stored locally by macOS for Clip; the interface follows your macOS preferred language.

Permissions

Clip requests Screen & System Audio Recording permission because macOS uses that permission for reading selected screen pixels. Clip does not record or save video and does not request Accessibility permission or simulate scrolling.
