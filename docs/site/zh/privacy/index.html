Clip 的设计是：在你的 Mac 上处理截图。

Clip支持English

最后更新：2026 年 9 月 11 日

Clip 处理什么

开始截图时，Clip 只读取你框选区域内的屏幕像素。滚动截图会在你滚动期间把画面保留在内存中，用于验证连续性并拼接结果。高级模式的 OCR 使用 Apple 的本机 Vision 框架。

Clip 保存或发送什么

  • Clip 不需要账号，也不会把截图、OCR 文字或使用数据发送到服务器。
  • Clip 不包含分析、广告、追踪或云同步。
  • 普通结果会写入 macOS 系统剪贴板。除非你明确点击下载，Clip 不会创建图片文件。
  • 点击下载后，Clip 会在“下载”文件夹写入 PNG。截图模式和快捷键等本地偏好由 macOS 为 Clip 保存；界面跟随 macOS 的首选语言。

权限

Clip 请求“屏幕与系统音频录制”权限，因为 macOS 使用这一权限读取用户选择的屏幕像素。Clip 不录制或保存视频，也不请求辅助功能权限，不模拟滚动操作。
