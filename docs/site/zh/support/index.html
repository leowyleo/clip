反馈问题

如果遇到可复现的问题，请在 GitHub Issues 提交，并附上 macOS 版本、Mac 芯片架构、截图模式和简短的问题描述。除非你愿意公开分享，否则不要上传私人截图。

也可以发送邮件至 leowy.lwy@gmail.com。

联系我们前可以先检查

  • 确认 Clip 已在“系统设置 → 隐私与安全性 → 屏幕与系统音频录制”中获准。
  • 用更小、内容稳定的区域重新尝试。
  • 滚动截图时正常操作原 App，并在内容完成后点击“完成”。
