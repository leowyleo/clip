Clip · macOS

框住，就能粘贴。

一款本机优先的截图工具，把你看见的内容用最短路径变成可以粘贴的图片。

隐私支持English

按下快捷键，自由框选一个区域，松开鼠标，图片立即进入系统剪贴板。

面对可滚动内容时，框选视口并正常滚动。Clip 在内存中保留 ScreenCaptureKit 画面，验证连续性后拼成长图，并在你完成时复制。

尽量不打扰你

Clip 不需要账号，没有云同步、行为分析或特定 App 适配器。截图和 OCR 都在本机处理。如果无法证明滚动结果可靠，Clip 会明确失败，而不是返回一张看似完成但内容错误的图片。

Clip 由行与未见 / Leowy 制作。需要 macOS 13 或更高版本。
