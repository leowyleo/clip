# Clip 产品设计文档

版本：0.1
平台：macOS 13+

## 一句话定义

**框住，就能粘贴。**

Clip 是从 Mac 屏幕上的可见内容到系统剪贴板的最短路径。它的核心不是“制作长图”，而是截图：普通截图自由框选，滚动截图只是同一种框选体验向屏幕之外的自然延伸。

## 用户要完成的两件事

### 区域截图

1. 按下区域截图快捷键。
2. 自由框选任意矩形区域。
3. 极简模式下，松开鼠标即完成截图并直接粘贴。
4. 高级模式下，截图原位明亮停留，选区外持续低亮，不额外保留边框；默认不激活画笔，选框下方提供马赛克、`T` 文字、OCR、矩形、圆形、直线、箭头线、下载和对号完成按钮。

### 滚动截图

1. 按下滚动截图快捷键。
2. 框选可滚动视口。
3. 选区线框固定留在桌面上，鼠标操作穿透线框；用户直接在原应用中向上、向下滚动或短暂回滚，Clip 在内存连续取帧并记录已经覆盖的内容。
4. 点击“完成”，线框消失并生成可信长图；极简模式直接进入剪贴板，高级模式进入同一套长图编辑工具。

两种能力共用同一种框选语言和同一种剪贴板交付方式，但使用不同快捷键。高频的普通截图不应被模式选择器打断。

## 第一版功能

- 区域截图和滚动截图的独立全局快捷键；
- 任意矩形框选，支持 Retina 和多显示器坐标；
- 本地屏幕截取、PNG 编码和系统剪贴板输出；
- 极简与高级两种截图体验，默认保持极简；
- 高级模式提供马赛克画笔、文字备注、本地 OCR、矩形和圆形标记；
- 高级编辑期间只用选区明亮、外围低亮表达视觉焦点，不额外显示边框；拖动标注时明暗关系不跳变；
- 完成后只显示短暂的“已复制”反馈；
- 用户自己控制滚动，Clip 不识别应用名称，也不接管输入；
- 双向视觉位移匹配、固定顶部区域容错、重复帧剔除和回滚去重；
- 支持完成、取消与尺寸上限；
- 拼接不确定时明确失败，诊断分片仅在后台保留；
- 仅在第一次截图时引导屏幕读取权限。

## 不做什么

- 不做账号、云同步、团队协作或行为分析；
- 不做录屏、截图历史库或通用图片编辑器；
- 不读取浏览器 DOM，不针对应用名称编写适配器；
- 不绕过 DRM、受保护窗口或 macOS 的系统限制；
- 不把无法证明连续性的图片伪装成成功结果。

## 设计哲学

### 聚焦一个承诺

Clip 只优化一条链路：**看见 → 框选 → 粘贴**。新功能只有在缩短或增强这条链路时才进入产品。滚动截图不是独立工作台，而是框选截图的自然延伸。

### 复杂留给产品

用户只看到框选、完成或清楚的失败原因。帧数、重叠率、置信度、滚动距离、缓存路径和拼接算法都应退到界面之后。

### 从头到尾负责

产品不以“发出了滚动事件”或“生成了一张图片”为完成。只有框选区域被可靠截取、拼接得到验证，并成功进入剪贴板，用户任务才算结束。

### 克制胜过堆叠

没有常驻主窗口，没有启动时模式选择页，没有默认生成文件，没有登录，也没有云端。极简模式维持最短路径；只有用户在设置中主动选择高级模式时，选区工具才出现。

### 真实胜过看起来可用

一张精致但断裂、重复或缺失内容的长图是失败。低置信度、动态内容、受保护内容和尺寸超限必须停止并说明原因；有疑问时宁可不交付。

### 隐私是默认状态

捕获、分析和拼接全部在本机完成。核心功能离线可用，不要求账号，不上传截图。默认结果只进入剪贴板；仅当用户明确点击下载按钮时，才在“下载”目录创建 PNG。

## 关键交互

- 默认区域截图快捷键：`⌃⌥4`；
- 默认滚动截图快捷键：`⌃⌥5`；
- 两组快捷键均可在设置中重新录制；
- 设置可选择“极简”或“高级”，默认“极简”；
- 高级工具条紧贴原选框下方；滚动长图保持选框宽度并可在选框内纵向浏览和编辑；
- 马赛克默认关闭，点击马赛克图标后才允许涂抹；
- 文字工具使用明确的 `T` 图标；点击落点后自动聚焦，输入框随内容扩展，回车确认并自动退出文字工具；
- OCR 使用 macOS 本地识别，成功后关闭选区、保留识别文字到剪贴板，并提示“文字 OCR 复制成功”；
- 直线和箭头线均由用户拖动起点与终点，箭头方向跟随拖动方向；
- 下载按钮将当前编辑结果另存为 PNG 且不关闭编辑器；对号按钮完成并复制图片；
- 框选时显示实时遮罩、清晰边界与像素尺寸；
- `Esc` 始终取消，并且不改变剪贴板；
- 滚动截图由用户自己滚动，点击“完成”结束；
- 滚动过程中选区线框保持固定、鼠标穿透，且不进入最终图片；
- 选区外只显示一个“完成”按钮，且不会进入截图内容；
- 内部以连续静态帧跟踪滚动，不编码、不保存视频；
- 控件点击目标至少 40 × 40 pt；
- 成功后只显示“已复制”，约一秒后自动消失；
- 失败只说明结果和可执行的下一步，不展示算法或缓存路径；
- 最终处理超过安全时限时必须停止并明确失败；
- 权限只在相应能力第一次真正需要时请求。

## “任意 App”的边界

"任意 App"指 macOS 允许读取其可见像素，并且用户能够让选中区域产生连续纵向内容的应用。Clip 不依赖浏览器、Finder、PDF 阅读器或聊天软件的内部结构，因此能力不被特定应用名单限制。

受保护内容不会被绕过；视频、动画、持续刷新的信息流或没有稳定视觉重叠的内容，可能因为无法证明拼接连续性而被拒绝。

## 参考对象

- macOS 系统截图：即时、克制、系统级一致性；
- Shottr：速度与精确框选；
- CleanShot X：轻量的截图后交付；
- PixPin、Snipaste：不依赖应用内部结构的截图交互。

Clip 不复制这些工具的功能清单，只借鉴它们缩短用户路径的方式。
