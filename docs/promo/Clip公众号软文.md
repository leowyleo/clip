# 我做了一个“框住，就能粘贴”的 Mac 截图工具

> 真正顺手的工具，不是让你看到更多功能，而是让你更少意识到它的存在。

![Clip 公众号封面](wechat-cover.png)

每天工作时，我都会截很多图：发一个页面细节、记录一条报错，或者截取一段聊天。

真正需要的动作其实很简单：**框住它，然后粘贴出去。**

但不少截图工具会在中间加入预览、保存、命名和各种按钮。功能越来越多，注意力也被一次次打断。

所以，我做了 Clip。

## 截图不应该打断工作

Clip 最核心的体验只有三个动作：**框选、松开、粘贴。**

截图完成后，图片直接进入剪贴板。打开微信、飞书、邮件或文档，按下 `⌘V` 就能使用。

操作路径：框选 → 松开 → 在微信中粘贴。

## 滚动截图，也应该由你控制

使用滚动截图时，Clip 会把选区固定在屏幕上。

你照常使用鼠标或触控板滚动页面，想截到哪里就滚到哪里，最后点击对号完成。

Clip 只负责连续记录画面变化，并把内容拼成一张长图。它不会替你滚动，也不会生成视频；边框、按钮和其他界面都不会出现在结果里。

操作路径：框选 → 手动滚动 → 点击对号 → 粘贴长图。

## 简单，但不简陋

Clip 默认使用极简模式，不主动展示多余工具。需要时，可以切换到高级模式，使用马赛克、文字、箭头、线条、OCR 和下载功能。

- 不需要账户
- 不上传截图
- 不依赖云端
- 中文、英文界面可切换

## 为什么开源？

因为我不想继续闭门猜测“用户可能需要什么”。

Clip 已经免费开源。我更想知道：它是否真的能让截图少一个步骤，让工作少一次中断。
